# Spotify Song Lookup

## Overview
The Spotify Song Lookup application allows users to search for songs and retrieve detailed information about them. Users can find songs by entering their titles or artist names, and the app provides relevant song information, including album details, artist profiles, and more.

## Features
- **Song Search:** Users can search for songs by title or artist.
- **Detailed Info:** Displays detailed information about the song, artist, and album.
- **User-friendly Interface:** A clean and intuitive interface that enhances user experience.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/WillemBarendKruger/WPR371_Assignment1.git
   ```
2. Navigate to the project directory:
   ```bash
   cd WPR371_Assignment1
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```
4. Run the application:
   ```bash
   npm start
   ```

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js
- **API:** Spotify API
